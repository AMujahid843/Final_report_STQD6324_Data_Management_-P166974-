This project analyses global development patterns using key socioeconomic, healthcare and environmental indicators across countries. It explores population distribution, GDP per capita, and life expectancy trends to understand differences in development levels worldwide. In addition, it examines relationships between indicators such as GDP per capita, CO₂ emissions, health expenditure, mortality rates, HIV incidence, and doctor density to uncover how economic and healthcare factors influence population health and sustainability. The project involves the applications of data management and data science.
